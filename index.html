Aturan Penting Compiler
  • Nama Program: Maksimal 8 karakter A-Z dan angka, diawali huruf (contoh: RUMUS01).
  • Variabel: Hanya huruf tunggal 1 karakter: A sampai Z.
  • Tanda Petik: Hanya karakter teks ASCII standar. Jangan gunakan emoji atau huruf khusus di dalam teks.
  • Komentar: Gunakan # atau // untuk catatan; compiler akan mengabaikannya.
Langkah Memasukkan .g1m ke Kalkulator
  1. Hubungkan kalkulator Casio fx-9860GII ke PC menggunakan kabel USB mini.
  2. Pada layar kalkulator, pilih opsi F1 (Flash / Data Trans) jika muncul pilihan koneksi.
  3. Buka software resmi CASIO FA-124 di Windows Anda.
  4. Pada panel kiri FA-124, klik kanan pada Memory Image default atau buat baru, lalu klik Import.
  5. Pilih file .g1m yang baru saja Anda download dari web ini.
  6. Klik tombol Connect pada toolbar FA-124 untuk menghubungkan kalkulator.
  7. Seret (drag and drop) program dari Memory Image ke sisi kalkulator (Main Memory).
  8. Cabut kabel, tekan tombol MENU di kalkulator, masuk ke PRGM, dan jalankan program Anda!
